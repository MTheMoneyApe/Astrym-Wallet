01 · PRUEBA ASTRYM

Elige cómo quieres probarlo

Son tres superficies distintas. La webapp y la PWA usan el preview experimental; la extensión se compila localmente desde el repositorio.

01 / WEB

Astrym Webapp

Abre la wallet en una pestaña del navegador, en formato de aplicación completa. No necesitas instalar una extensión.

Probar Webapp ↗ Preview experimental · Stellar Testnet
02 / BROWSER

Extensión de navegador

Prepara la extensión MV3 para Chrome o Chromium. Descarga el código, instala dependencias y genera el paquete localmente.

  1. Descarga o clona el repositorio.
  2. Ejecuta pnpm install.
  3. Ejecuta pnpm --filter @solanym/extension build.
  4. Carga packages/extension/dist en chrome://extensions con el modo desarrollador.
Código e instrucciones ↗ No hay todavía un instalador público de Chrome Web Store.
03 / ANDROID

Android · PWA

Abre la Webapp en Chrome para Android y añádela a la pantalla de inicio. Se instala como PWA; no es un APK nativo.

  1. Abre la Webapp desde tu móvil.
  2. Abre el menú ⋮ de Chrome.
  3. Selecciona «Instalar aplicación» o «Añadir a pantalla de inicio».
Abrir PWA en Android ↗ Preview experimental · requiere navegador compatible.

Aviso: utiliza únicamente una wallet desechable de Stellar Testnet. No introduzcas frases semilla con fondos reales. Estas versiones son experimentales y no están certificadas para producción.

02 · ESTADO HONESTO

Investigación, implementación y validación

Privacidad de red
