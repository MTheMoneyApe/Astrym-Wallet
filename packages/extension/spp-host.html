Storage lab (Fase 5D)

Run stays disabled while phase gate is false
  1. Load unpacked packages/extension/dist in chrome://extensions.
  2. Open chrome-extension://<ID>/spp-host.html or use the webapp embed.
  3. Click Comprobar SDK → facade phase ready.
  4. Click Inicializar WASM → WASM phase ready.
  5. Confirm Storage gates → ready-for-lab. Run enables only if STORAGE_LAB_EXECUTION_AUTHORIZED is true.
  6. Deposit / transfer / withdraw remain blocked until the Testnet broadcast gate is approved.
